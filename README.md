# GoVoort

This framework is a yearning toward, simplicity, safety, compatability and joy.
It is a rewind, revision of first principles and a sort of "back to basics" for web development.
Much of web development is dominated by the Node ecosystem full of large frameworks constantly
trying to solve problem that it itself seemed to have created. A continuos pendulum between design
ideas such as client-side vs serverside vs both and back again.

The web used to be simple, powerful and dare I say safe before any of the node frameworks started 
taking over. 

This is an experimental framework meant to allow "full stack" development of the web, yet again.
This time we try to stay naive, simple and give the power back to the developer. 
No you cannot get rid of JS yet because at some point you will need a client side event handler but,
you may be surprised how far you can get with very little of it.

Go forth / gaan voort, and try web a little different.
